#### 计算机网络为什么要分层？

因特网是极为复杂的系统，它包含大量的软件以及硬件系统，大量的应用程序和协议等等，面对这种庞大且**复杂**的系统，将其化简分层是极其有必要的，可以将各层之间**解耦**。

#### 计算机网络是怎么分层的？

**OSI 七层模型**

它是国际标准化组织提出的一个网络分层模型。OSI 的七层体系结构概念清楚，理论也很完整，但是它**比较复杂而且不实用**，而且有些功能在多个层中重复出现。

**TCP/IP 四层模型**

应用层：**为用户提供服务**。（HTTP，DNS）

传输层：**处理主机到主机的通信**（TCP、UDP）

网络层：将传输层的数据（段或数据报）加上 IP 头部，形成数据包，然后进行**路由和寻址（决定数据在网络中游走的路径）**目标主机。

链路层：将网络层传来的数据包封装成帧，并在**物理介质上传输**这些帧，至目标主机。

#### 计算机网络中，数据如何在各层中传播？描述一下打开百度首页后发生的网络过程？

> https://xiaolincoding.com/network/1_base/what_happen_url.html

![image-20250122170319087](/Users/mato/Library/Application Support/typora-user-images/image-20250122170319087.png)

1）解析 URL，开始构造 HTTP 请求报文；

2）应用层 DNS 域名解析，将域名解析为 IP 地址；

3）传输层构建 TCP 三次握手；

4）然后到了网络层，请求头加上 IP 地址，进行路由寻址；

5）然后数据链路层，通过 ARP 协议，获取路由器的 MAC 地址，加在请求头上；

6）然后~~物理层~~，把数据包转发给路由器；

7）完成三次握手之后，用户端将 HTTP 报文传给客户端；（第一次握手 syn报文，也是需要经过 ip 层，数据链路层，物理层，发送出去的；第三次握手可以携带数据）

8）客户端收到后，进行解析渲染。

###### MAC 地址和 IP 地址的关系：

MAC 位于数据链路层，IP 位于网络层。

IP 地址用于**标识终点设备的位置**，是**抽象的**；**实际数据传输**过程需要使用 MAC 地址进行逐跳传输。

###### 服务器 ping 不通但是 http 能请求成功，会出现这种情况吗？

会。ping 时基于网络层的 ICMP 协议（发送回显请求（一种数据包吧）并接收回显响应，用于测试网络连通性、延迟和丢包情况），HTTP 基于传输层的 TCP 协议，有可能服务器防火墙禁止 ICMP 协议。

###### 交换机和路由器区别

路由器：管理**不同网络之间的设备**，通过 IP 地址转发数据。（主要通过 IP 地址来做**路由决策**，仍然需要 MAC 地址）

交换机：管理**同一网络内的设备**，通过 MAC 地址转发数据。

#### 计算机网络中的安全问题

###### DDoS

分布式拒绝服务攻击，通过**大量设备**同时向目标服务器、网络或应用程序发送大量请求，**导致服务器资源耗尽，无法正常响应合法用户的请求**。

如何解决：限制单个 IP 地址的请求速率，或者直接禁掉；负载均衡，防止单点故障。

###### DNS 劫持

黑客劫持了 DNS 服务器，篡改了 DNS 解析结果，**将域名解析到错误的 IP 地址上**，

解决办法：手动更换公 DNS 服务器，绕过被劫持的 DNS 服务器。
